아래는 앱에 포함된 증례의 일부 상황을 요약한 것이다. 진단을 맞히는 퀴즈로 보기보다, 아직 듣지 못한 정보가 무엇인지 생각해 본다.

눕거나 숨을 깊이 쉴 때 더 아프다자세와 호흡에 따른 변화, 최근 몸 상태, 이전 통증과의 차이

각 행은 서로 다른 환자 상황이다. 한 환자의 답변으로 합치거나, 특정 표현 하나만으로 진단을 확정하지 않는다.

환자의 말에서 다음 질문 찾기

여기서 어떤 질문을 이어 갈까?

예: “지금도 계속 아프세요?”라고 현재 상태를 확인하고, 통증이 어떻게 느껴지는지와 다른 부위로 퍼지는지를 하나씩 묻는다. “운동할 때 시작됐군요”처럼 환자가 말하지 않은 정보를 요약에 넣지 않는다.

질문 여러 개를 한꺼번에 나열하면 환자가 어떤 질문에 답했는지 놓치기 쉽다. 답변을 받은 뒤 아직 비어 있는 정보를 확인하는 식으로 이어 간다.

질문 목록을 대화에 붙이는 방법

문진 중 돌아볼 질문 묶음
확인할 정보말해 볼 문장
시작과 경과“처음 시작했을 때부터 지금까지 통증이 어떻게 달라졌어요?”
위치와 퍼짐“어디가 제일 아프세요?”라고 먼저 묻고, 다른 부위로 이어지는지 확인한다.
악화·완화 상황“어떤 때 더 아프고, 어떻게 하면 조금 나아지세요?”
함께 나타난 변화숨참, 식은땀, 어지러움 같은 동반 증상을 환자가 이해하는 말로 하나씩 확인한다.
환자의 생각과 걱정“어떤 문제일까 가장 걱정되세요?”

이는 문진 연습의 일부이며 전체 평가 항목이나 진료 지침은 아니다. 새로 생긴 심한 흉통이나 불안정한 상태를 다루는 모의 상황에서는 긴 문진을 끝내는 것보다 즉각적인 평가·도움 요청을 먼저 고려한다.

한 환자를 복습한 뒤 다른 환자로

  1. 웹 앱에서 한국 의사국시 CPX → ‘가슴이 아파요’를 고른다.
  2. 처음에는 연습 범위를 병력청취로 좁혀 질문과 답변에 집중한다.
  3. 결과표에서 빠진 질문 하나와 잘못 요약한 말이 있는지 확인한다.
  4. 같은 환자를 다시 해 본 뒤, 케이스 목록에서 다른 증례를 골라 같은 질문 틀이 통하는지 본다.

앱에서는 아직 연습하지 않은 증례를 우선 선택한다. 전체 케이스의 구성과 선택 방법은 케이스 안내에 정리했다.

2026년 10월 21일 콘텐츠 기준으로 ‘가슴이 아파요’ 스테이션에 36개의 고유 증례가 있습니다. 앱의 학습용 증례 수이며 국시원 기출문제 수가 아닙니다.
이 글의 대화가 앱에서 그대로 나오나요?
아닙니다. 대화는 문진 흐름을 설명하기 위한 가상 예시입니다. 앱의 실제 답변은 선택한 증례와 질문에 따라 달라집니다.
전체 케이스가 무료인가요?
네. 앱 이용료와 케이스 추가 결제가 없으며 전체 케이스에 유료 잠금이 없습니다. AI 대화·채점에는 본인의 Gemini API 키가 필요합니다. Google 무료 등급의 사용 한도가 적용되며, 유료 등급을 직접 선택하면 별도 API 요금이 발생할 수 있습니다.
