무료로 연습하기 ↗케이스 살펴보기

AI 대화·채점에는 본인의 Gemini 무료 키가 필요합니다. 무료 한도 내 이용하며, 키 없이 공부 노트·체험 환자부터 볼 수 있습니다.

한국어 AI 모의환자(AI SP)와 문진하고, 진찰과 계획을 설명하고, 놓친 항목을 돌아본다. 아이폰·아이패드·PC·안드로이드에서 48개 임상표현과 다양한 증례를 연습할 수 있다.

2026년 10월 기준 · 시험 관련 사실은 한국보건의료인국가시험원(국시원) 공개 자료를 따랐다

대본을 준비하고, 진찰법을 확인하세요

CPX 대본을 준비할 때 필요한 문진 질문 예문과 신체진찰 목록을 바로 읽을 수 있습니다. 설치·로그인·API 키 없이 열립니다.

임상표현별 문진·질문 예문전체 흐름을 보거나 문진만 골라 읽으세요. 계통별 탐색과 증상 검색으로 필요한 자료를 찾습니다.문진·예문 보기 → P/E 신체진찰 목록·Atlas증상별 진찰 항목에서 술기 카드로 이어집니다. 동작·환자에게 할 말·소견과 주의점을 확인하세요.P/E 자료 보기 →

무엇을 할 수 있나

  • AI 표준화 환자와 음성 면담. 환자는 묻는 것에만 대답하고, 주호소도 문제지가 아니라 환자가 직접 말한다. 소아 증례는 보호자가 대신 대답한다.
  • 2026년 형식 문제지. 환자 이름과 나이, 장소, 활력징후, 과제(병력 청취 · 신체진찰 · 추정진단과 계획 논의)만 적힌 문제지를 보고 시작한다.
  • 12분 타이머. "종료 2분 전"과 "시험 종료" 알림이 울리고, 실전 타이머를 켜면 12분에 스테이션이 끝난다.
  • 말로 하는 신체진찰. 진찰을 하겠다고 말하면 환자가 대본대로 반응하고, 연습 모드에서는 해당 소견이 화면에 뜬다.
  • 한국어 채점표. 병력 · 신체진찰 · 환자 교육 체크리스트, PPI 6개 영역(4단계), 추정진단과 감별진단 · 검사 · 치료 계획을 항목별로 보여 준다. 놓친 항목에는 예시 문장이 붙는다.
  • 친구와 역할극. 한 명은 의사, 한 명은 환자 대본을 보고 연기한다. 휴대폰 한 대가 대화를 녹음하고, AI가 화자를 구분해 받아쓴 뒤 같은 채점표로 채점한다.
  • 실전 모의고사. 서로 다른 임상표현 9개(또는 3개) 스테이션을 연속으로 치르고, 마지막에 한꺼번에 결과와 추정 합격 여부를 본다.
  • 공부하기. 스테이션별 감별진단 묶음, 꼭 물어야 하는 항목(★), 예시 문장을 API 키 없이 읽을 수 있고, 내가 자주 놓친 항목이 모인다. 계통별 문진·신체진찰 정리 바로 보기 →
  • 기본진료술기 자가 점검. 술기 9개의 단계별 체크리스트와 12분 타이머.

앱 이용료 0원, AI 무료 키의 이용 조건

앱 이용료는 0원이다. 전체 케이스를 같은 조건으로 이용하며 유료 플랜, 크레딧 충전, 결제창, 회원가입, 광고가 없다.

서버 비용을 구독료로 받는 대신, AI 환자와 채점이 사용자가 직접 발급받은 Google Gemini API 키로 동작하기 때문이다. 키는 Google AI Studio에서 카드 등록 없이 무료 등급으로 받을 수 있고, 앱의 첫 화면이 발급 과정을 안내한다. 무료 등급에는 사용 한도가 있고, Google 유료 등급을 직접 선택하면 별도 API 요금이 적용된다. 무료 등급의 한도와 데이터 사용 조건은 Gemini API 무료 티어 정리에 적어 두었다.

무료 등급에서는 Google이 대화 내용을 서비스 개선에 쓸 수 있다. 실제 환자 정보나 개인 정보는 말하지 않는다. 키가 없어도 공부하기와 술기 체크리스트, 체험 환자는 바로 쓸 수 있다.

알아 둘 한계

  • 신체진찰은 말로만 진행한다. 손의 위치나 기법은 평가하지 못한다.
  • 기본진료술기는 AI가 채점하지 않는다. 체크리스트를 보고 스스로 점검한다.
  • 모의고사의 합격 판정은 추정이다. 실제 기준 점수는 스테이션마다 다르고 공개되지 않는다.
  • 역할극 모드의 화자 구분은 두 사람이 동시에 말하면 틀릴 수 있다.
  • 증례의 진찰 소견은 차트 표기대로 영어로 표시된다.
  • 음성 진료 중에 화면을 잠그거나 다른 앱으로 가면 대화가 일시정지된다. 진료하는 12분 동안은 화면을 켜 둔다.
  • 기록은 쓰는 브라우저에만 저장된다. 계정이 없어서 다른 기기와 자동으로 동기화되지 않는다.

시작하는 방법

  1. 안드로이드는 Google Play에서 Bedside English: Talk & Train을 설치한다. 아이폰·아이패드·PC는 브라우저에서 bedsideenglish.github.io/app을 열고, Safari의 공유 버튼 → '홈 화면에 추가'를 해 두면 앱처럼 열린다.
  2. 첫 실행 화면(또는 설정의 연습 종류)에서 한국 의사국시 CPX를 고른다.
  3. '키 없이 먼저 둘러보기'로 48개 공부 노트와 체험 환자부터 바로 보거나, 안내에 따라 무료 Gemini API 키를 붙여 넣는다.
  4. 스테이션 탭에서 증상을 고르고 문제지를 읽은 뒤 면담을 시작한다.

처음이라면 연습 범위를 "병력 청취만"으로 좁히고 체크리스트 힌트를 켜거나, 도서관이라면 타이핑으로 시작하면 부담이 적다.

자주 묻는 질문

처음만 무료고 나중에 결제하라고 하지 않나요?
앱 이용료는 0원이며 유료 플랜·결제창·크레딧 충전이 없습니다. AI 대화와 채점은 본인의 Gemini API 키를 사용합니다. Google 무료 등급의 한도 안에서 이용하면 비용 없이 연습할 수 있고, 유료 등급을 직접 선택하면 별도 API 요금이 적용됩니다. 키 없이도 공부 노트·술기 체크리스트·체험 환자를 볼 수 있습니다.
실제 국시 채점표로 채점하나요?
아닙니다. 국시원의 채점표와 배점은 비공개입니다. 앱의 체크리스트는 공개된 시험 안내(문제지 양식, 환자-의사 관계 평가 영역, 임상표현 목록)를 참고해 자체적으로 만든 연습용 기준이며, 학교나 실제 시험과 다를 수 있습니다.
혼자서도 연습할 수 있나요?
네. 한국어로 대답하는 AI 표준화 환자와 음성으로 12분 스테이션을 진행할 수 있습니다. 친구가 있다면 한 명이 환자 대본을 보고 연기하고, 휴대폰이 대화를 녹음해 채점하는 역할극 모드를 쓸 수 있습니다.
48개 임상표현을 모두 연습할 수 있나요?
네. 진료문항 48개 임상표현 모두에 스테이션이 있고, 목록 밖의 흔한 증상을 다루는 보충 스테이션이 더 있습니다. 홈 화면에서 지금까지 만난 항목 수를 확인하고 아직 안 해 본 항목을 바로 시작할 수 있습니다.
신체진찰과 기본진료술기도 연습되나요?
신체진찰은 말로 진행합니다. 어떤 진찰을 하겠다고 말하면 환자가 대본대로 반응하고, 연습 모드에서는 그 진찰의 소견이 화면에 표시됩니다. 손기술이 필요한 기본진료술기 9개는 AI가 채점하지 않고, 단계별 체크리스트와 12분 자가 점검 타이머로 제공합니다.
아이폰이나 PC에서도 쓸 수 있나요?
네. 웹 앱이라 아이폰·아이패드 Safari, PC의 Chrome·Edge, 안드로이드 Chrome에서 주소만 열면 됩니다. 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

한국 CPX 트랙에서 연습하기

키 없이 공부 노트와 체험 환자를 먼저 볼 수 있다. AI 환자와 다양한 케이스를 연습하려면 본인의 Gemini 무료 키를 연결한다. 앱 이용료는 0원이며 Google 무료 등급의 한도가 적용된다.
