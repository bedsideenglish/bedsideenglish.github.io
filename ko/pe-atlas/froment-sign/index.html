프로망 징후 — 종이 옆집기

종이를 옆집기할 때 자신경 지배 엄지모음근의 약화를 보상하는 엄지 IP 관절 굴곡을 관찰합니다.

그림으로 보는 진찰

A · 옆집기: 엄지와 검지 옆면 사이에 종이

B · 예시: 먼쪽으로 가볍게 당겨도 IP 유지

C · 별도 양성 예시: FPL 보상으로 IP 굴곡

진찰 그림 불러오는 중…

환자 자세

드래그하여 자유롭게 회전

시행 순서

  1. 엄지 통증이나 관절 제한이 평가를 방해하는지 확인하고 양손 비교를 설명합니다.
  2. 종이를 엄지와 검지의 노쪽 옆면 사이에 둡니다. 손끝끼리 맞대는 집기와 구별합니다.
  3. 엄지 IP 관절을 편 채 종이를 놓치지 않게 하고, 검사자는 엄지 길이 방향의 먼쪽으로 가볍게 당깁니다.
  4. IP 관절을 보며 양손을 비교합니다. 종이를 놓침, IP 굴곡, 통증과 다른 보상 동작을 따로 기록합니다.
  5. 손가락 벌림·모음, 자신경 영역 감각과 더 넓은 신경 진찰을 추가해 병변 위치를 평가합니다.

환자에게 이렇게 말하세요

  1. 검지 옆면에 엄지로 종이를 잡아 주세요.
  2. 제가 살짝 당길 때 엄지 끝마디를 편 채 유지해 보세요.

양성 소견의 의미

과제 중 엄지 IP 굴곡이 생기면 프로망 양성입니다. 정중/앞뼈사이신경의 긴엄지굽힘근(FPL)이 약한 엄지 모음을 보상합니다. 이것만으로 팔꿈치·손목 병변을 구별하지 못합니다.

음성 소견의 의미

IP가 유지되어도 초기 자신경병증을 배제하지 못합니다. 통증, 방법과 원래 엄지 가동성이 결과에 영향을 줍니다.

근거와 한계

근력 등급이 아니라 운동 보상 징후입니다. 보편적 민감도나 당기는 힘의 역치를 부여하지 않습니다.

주의할 점

  1. IP 굴곡은 프로망이며 MCP 과신전인 잔느 징후와 구별합니다.
  2. 처음부터 엄지 끝을 굽혀 종이를 걸지 않게 합니다.
  3. IP 유지와 굴곡 그림은 각각의 교육 예시이며 한 환자가 정상에서 질환으로 변하는 영상이 아닙니다.

함께 살펴볼 진찰

  • 통증궁 (Painful arc)견봉하 충돌(어깨 충돌 증후군)을 찾는 검사입니다. 팔을 옆으로 들어 올리면 범위의 중간에서 회전근개 힘줄과 점액낭이 견봉 아래에서 눌려, 대략 60~120도 사이에서 통증이 생기고 그 이상에서는 줄어듭니다.어깨와 팔↗
  • 엠티 캔 검사 (Jobe)극상근을 검사합니다. 팔을 견갑골면으로 들어 올리고 엄지를 아래로 향하게 하면, 아래로 누르는 힘에 맞서 팔을 버티는 주된 근육이 극상근입니다. 힘이 약하면 파열이나 힘줄 질환을, 힘은 정상인데 아프면 건병증을 의심합니다.어깨와 팔↗
  • 팔 떨어뜨리기 검사 (Drop arm test)큰 또는 전층 회전근개 파열, 주로 극상근 파열을 찾는 검사입니다. 회전근개가 온전하면 외전 90도에서 팔을 부드럽게 내릴 수 있지만, 파열이 있으면 그러지 못합니다.어깨와 팔↗
  • 니어 충돌 검사 (Neer test)견봉하 충돌을 찾는 검사입니다. 견갑골을 고정한 채 팔을 안쪽으로 돌려 앞으로 끝까지 올리면 상완골 대결절과 극상근 힘줄이 견봉 앞쪽에 눌려 통증이 재현됩니다.어깨와 팔↗
  • 호킨스-케네디 검사 (Hawkins–Kennedy test)견봉하 충돌증후군을 선별합니다. 어깨를 90도 들고 팔꿈치를 굽힌 상태에서 수동으로 내회전하면 큰결절과 회전근개 힘줄(주로 가시위근)이 오구견봉궁 쪽으로 밀리면서 통증이 재현됩니다.어깨와 팔↗
