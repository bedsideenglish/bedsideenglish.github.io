오버 검사: 지지한 고관절 내전

옆으로 누워 골반을 고정한 상태에서 수동 고관절 내전을 평가합니다.

그림으로 보는 진찰

좌측으로 누워 위 다리 지지; 무릎 90도

외전한 고관절을 부드럽게 신전; 골반 정렬 유지

지지하며 내전 허용; 아래로 누르지 않기

지지한 다리를 다시 외전

고관절 중립 복귀; 반대쪽 비교

진찰 그림 불러오는 중…

드래그하여 자유롭게 회전

시행 순서

  1. 검사하지 않는 쪽으로 눕고 아래 고관절·무릎을 굽힙니다. 어깨와 골반을 수직 정렬하고 위 다리를 검사합니다.
  2. 위쪽 골반을 고정합니다. 위 허벅지·무릎을 지지하고 무릎을 약 90도로 굽힌 뒤 고관절을 부드럽게 외전·신전합니다.
  3. 정렬을 유지하며 다리 무게를 조절해 중력에 따라 내전하게 합니다. 통증·저항·골반 움직임이 생기면 멈춥니다.
  4. 가능한 범위와 증상을 기록하고 지지하며 시작 자세로 돌아옵니다. 같은 변형으로 좌우를 비교합니다.

환자에게 이렇게 말하세요

  1. 다리 힘을 빼세요. 내려올 때 제가 받치겠습니다. 아프면 말씀해 주세요.

양성 소견의 의미

골반 고정 시 내전 제한은 가동성 소견입니다. 이것만으로 장경인대 단축이나 장경인대 증후군을 확진하지 않습니다.

음성 소견의 의미

편하게 내전되어도 외측 고관절·무릎 통증의 원인을 배제하지 못합니다.

근거와 한계

사체 연구는 단순한 장경인대 길이 검사 해석에 의문을 제기합니다. 무릎 굴곡·신전 변형을 서로 대체하지 않습니다.

주의할 점

  1. 골반 회전·고관절 굴곡은 내전이 더 되는 것처럼 보이게 합니다. 다리를 침상까지 억지로 누르지 않습니다.
  2. 애니메이션은 예시 중립 내전에서 멈춥니다. 측정한 종말각·조직 긴장·양성을 재현하지 않습니다.

함께 살펴볼 진찰

  • 패트릭 검사 (FABER test)고관절과 천장관절에서 오는 통증을 유발합니다. 고관절을 굴곡, 외전, 외회전시켜 4자 모양(발을 반대쪽 무릎 위에 올림)을 만든 뒤, 반대쪽 골반을 고정하고 무릎을 침대 쪽으로 누릅니다.고관절↗
  • FADIR: 고관절 굴곡·내전·내회전고관절 굴곡·내전·내회전에서 익숙한 고관절 통증이 재현되는지 봅니다.고관절↗
  • 고관절 로그롤 — 수동 회전·통증 평가편안하게 편 다리를 한 덩어리로 부드럽게 돌려 고관절 회전이 평소 통증을 재현하는지 봅니다. 이 카드는 관절낭 이완을 보는 별도의 dial test 해석보다 수동 회전 시 통증 평가에 초점을 둡니다.고관절↗
  • 토마스 검사 (고관절 굴곡 구축)반대쪽 고관절을 굽혀 골반·허리의 보상 움직임을 제한했을 때 검사 쪽 고관절이 펴지는지 평가합니다. 침상 위에서 시행하는 기본 토마스 검사이며 다리를 침상 밖으로 내리는 변형 검사는 아닙니다.고관절↗
