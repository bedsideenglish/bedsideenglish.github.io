08 / FIELD NOTES

Before your first session.

Bedside English: Talk & Train is a personal open-source practice project, not a clinical system or medical device.

Is this useful before clinical rotations?
Yes. Survival Mode and Listening Lab are specifically useful for pre-med and early-year students who need faster, more flexible everyday English before clinical vocabulary becomes the main challenge.
What is actually random in Survival Mode?
The role, goal, contextual detail, twist, delivery style, voice, and best-effort accent profile can change. The purpose is to train understanding and recovery when the next line is not predictable.
Can I try it without an API key?
Yes. Demo Mode (desktop) and Mock voice mode (Android) run a guided practice flow without a key or microphone. Live AI voice and provider-based analysis require a supported API key.
Is the app completely free?
Both apps are free and open source. Provider-based live AI usage depends on the model, free tier, and plan attached to your own API key.
Why might my operating system show a warning?
Early open-source desktop releases are unsigned, so Windows SmartScreen may say “Windows protected your PC.” Click More info, then Run anyway — the file comes straight from this project’s GitHub Releases, and you’re welcome to inspect the source first.
