How to confirm a wait time and phone number in English

Catch the time and digits once, then repeat them back before the host sends a text.

Don’t guess the missing detail.

Catch it, ask for it again, and confirm it before the conversation moves on.

Quick answer

When a host gives a wait and phone-number ending, check the time first and repeat the digits slowly. Ask for one number again if you are unsure; do not guess. A brief readout lets the host correct a single digit before they send the text, which is easier than fixing a missed message later.

  1. Missed the wait

    “Sorry, how long is the wait?”

    Ask for the time alone.

  2. Missed a digit

    “Was the number ending 4-8-1-7?”

    Say each digit clearly.

  3. Need the text

    “About 20 minutes, and the number ends 4-8-1-7—right?”

    Confirm both details once.

Common failure points

Repair the interaction, not your confidence

A useful response gives the other person a clear way to help.

Saying a digit group too quickly

Say each digit separately when you confirm it.

Confirming the phone number but not the wait

Repeat both when the timing affects your plan.

Guessing one missing digit

Ask for that digit again before the text is sent.

Do not memorize one airport sentence. Reuse the confirmation pattern wherever a detail matters.

Short answers

Questions learners ask

How should I say phone digits?

Say one digit at a time when accuracy matters.

Can I ask for only the last four digits?

Yes. “Could I confirm the last four digits?” is natural and specific.

What if the wait is only an estimate?

Say “about” when you repeat it: “About 20 minutes, right?”
